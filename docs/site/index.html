A command-line tool, one binary

presenter

Write slides in Markdown or a Jupyter notebook, and get a reveal.js presentation in one HTML file that works offline. Live preview while you write, themes as files, PDF and PowerPoint export.

Download See the examples Source on GitHub

Download

Each release has one archive per platform: macOS (Apple silicon and Intel), Linux (x86_64 and arm64, glibc) and Windows (x64 and arm64). The binary needs nothing else at run time; reveal.js, KaTeX, the themes and the Sass compiler are inside it.

${download}

Or build from source with Rust 1.89 or newer: cargo install --path . in a checkout. The installation guide has the details.

In 30 seconds

presenter init talk                 # a deck, a presenter.toml and a small theme
cd talk
presenter serve slides.md --open    # live preview; edit slides.md and watch
presenter build slides.md           # Wrote dist/slides.html (6 slides, 1.8 MB)

Examples
